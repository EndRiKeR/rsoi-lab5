## Вариант 1: продажа билетов на самолет

### Запуск

Для запуска необходимо включить фронтенд и бэкенд.

### Фронтенд

В папке фронтенда `./spa` вводим следующие команды через Git Bash:

```bash
  npm run dev
```

Заходим на сайт по ссылке, указанной в терминале.

### Бэкенд

#### Локальный запуск
В корне проекта `./` находим файл `docker-compose.yml`. Собираем образы через Docker.

#### Minikube
В корне проекта запустить скрипт `./minikube-deploy/start.sh`.
Будет выполнена установка minikube, сборка сервисов, загрузка образов в minikube,
развертывание и тестирование.
